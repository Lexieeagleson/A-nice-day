A Nice Day

Did you enjoy the weather today?

iOS 17+ SwiftUI Xcode 15+ Swift 5.9+

About

A Nice Day is a minimal, journal-like iOS app that asks one simple question each day: "Did you enjoy the weather today?" It helps you track your daily weather experiences in a calm, non-judgmental way — recording not whether the weather was objectively good, but whether you personally enjoyed it.

Features

📝

Daily Prompt

One Yes/No question per day — simple and distraction-free.

🌡️

Weather Tracking

Automatically captures temperature, conditions, humidity, and wind speed.

📍

Location Logging

Records human-readable location (city, state, country) — no raw coordinates.

📊

Year Summary

Statistics showing enjoyment patterns and weather correlations over the year.

💾

Local Storage

All data stored privately on your device using Core Data — no cloud, no account.

🎨

Calm Design

Minimal, journal-like aesthetic with soft gradients and intuitive navigation.

Requirements

  • Xcode 15.0 or later
  • iOS 17.0 or later
  • Swift 5.9 or later
  • macOS Ventura 13+ (for Xcode)

How to Run

  1. Clone the repository Download the source code to your Mac. 
    git clone https://github.com/Lexieeagleson/A-nice-day.git
cd A-nice-day
  2. Open in Xcode Open the Swift Package manifest to launch the project in Xcode. 
    open Package.swift
  3. Select a simulator or device In the Xcode toolbar, choose an iPhone simulator (iOS 17+) or a connected device.
  4. Build and run Press ⌘R (or Product → Run) to build and launch the app.
  5. Grant location permission On first launch, allow location access ("While Using App") for full weather functionality. The app still works if denied.

Optional: Real Weather Data (WeatherKit)

By default the app uses a mock weather service. To enable real weather data via Apple WeatherKit:

  1. Add WeatherKit capability in Xcode Select your project → Signing & Capabilities → + Capability → WeatherKit.
  2. Enable WeatherKit in HomeViewModel 
    weatherService: WeatherService(useWeatherKit: true)
  3. Note WeatherKit requires an Apple Developer account, proper entitlements, and internet access on the device or simulator.
